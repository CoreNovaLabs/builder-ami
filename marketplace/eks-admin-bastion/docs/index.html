AWS Marketplace buyer guide

CoreNova EKS SSM Bastion

Private, zero-ingress EKS administration through AWS Systems Manager. Choose per-operator identity or a streamed administrative shell without exposing SSH or a public IPv4 address.

Choose a security mode

Recommended for production

Identity Relay

Kubectl tokens are generated from each operator’s local AWS role. The relay instance has no EKS API permissions. Use this when individual identity and namespace scope matter most.

Compare identity and audit tradeoffs

Audited Workstation

Operators share a scoped EC2 role, while SSM runs a non-root shell and streams the standard session to retained CloudWatch Logs. Use this when shell transcripts are required.

Read the security boundaries

Standalone AMI

The compatibility path for teams with their own Terraform, networking, IAM, and access-entry automation. You configure every control yourself.

Launch directly in AWS

  1. Subscribe in AWS Marketplace and choose Continue to Launch.
  2. Select Custom Launch, then Identity Relay or Audited Workstation.
  3. Choose Launch with CloudFormation Console.
  4. Select the VPC, private subnet, EKS cluster, and cluster security group.
  5. Keep View + Namespace + default for the first launch.

No CoreNova website redirect is required. The Marketplace AMI ID is injected into the template automatically.

Existing subscribers and upgrades
